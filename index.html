SEA-AD Sandbox

A collection of interactive tools and prototype applications for the Seattle Alzheimer’s Disease Brain Cell Atlas (SEA-AD). These applications provide access to gene expression, cell type, trajectory, neuropathology, and annotation exploration resources. Many of these tools are works in progress. We encourage feedback using the link below!

MTG Trajectory Viewer

Identify and visualize cell type-specific gene expression changes across AD pseudo-progression in MTG.

Launch App GitHub

SEA-AD Multiregion Viewer

Explore gene expression patterns in multi-region single cell data in the context of cell types, brain regions, and disease progression.

Launch App GitHub
Related app: developing mouse VIS

Neuropathology Viewer

Explore neuropathology images and associated measurements from multiple brain region in SEA-AD donors.

Launch App GitHub

Annotation Comparison Explorer (ACE)

Compare cell type annotations between SEA-AD and ten community studies of AD or user data from MapMyCells.

Launch App GitHub

Cell Hierarchy Gene Explorer (CHARGE)

Identify genes of potential biological interest in multiple cell type taxonomies (including SEA-AD MTG).

Launch App GitHub

Gene Knowledge Cards

Explore patterns of gene expression in the brain across multiple Allen Brain Atlases (including SEA-AD).

Launch App GitHub

Allen Brain Map Resource Finder

Visit a user-friendly entry point into tools and resources available on Allen Brain Map and SEA-AD.org.

Launch App Allen Brain Map
